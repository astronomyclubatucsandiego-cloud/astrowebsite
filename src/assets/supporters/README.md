# Sponsor and supporter logos

- Name each file after the organization's `slug` in `SUPPORTERS` (`src/config.ts`):
  - `ucsd-astronomy.jpg` for the Department of Astronomy & Astrophysics
  - `palomar.png` for Palomar Observatory
  - `sdaa.jpg` for the San Diego Astronomy Association
- Any of SVG, PNG, JPG or WebP works (SVG is sharpest). To replace a logo, swap the file and keep the name.
- Use the official logo the organization sends you, and only with their OK.
- The logo appears on the home page automatically. No code changes needed.
